    NODE_ENV=test node --require ./tests/pre-p2-routing/offline-network.cjs --import tsx \
      src/ai/brain/evaluation/run-baseline.ts /tmp/report.json

Tiers in the report:

- `tier1.deterministic` — real V1 routing predicates, intent normalizer and service-selection clarifier; reply language
  through the server-side authority (test boundary). The semantic LLM language resolver is withheld, so model-dependent
  language decisions are INDETERMINATE; `languageUnderResolverOutage` is a degraded-mode diagnostic only.
- `tier1.oracle` — POLICY CEILING. Real `buildEvidenceFirstAnswer` + `publishableKnowledgeManifest` with the provider
  stages replaced by a ground-truth oracle (truthful proposals and verdicts, identity composition). Measures whether V1
  would publish the correct outcome if the model were perfect. Not evidence of live semantic correctness.
- `tier2` — recorded genuine outputs replayed verbatim through the current pipeline (with input-drift detection), and
  recorded delivered replies graded deterministically. Meaning-level judgments are INDETERMINATE pending review.

Grades: only PASS and FAIL enter rates; rates are withheld below 5 graded results.

Environment note for this run: macOS-only rollup native binaries were bypassed in a scratch Linux VM with a stub
binding (loading only; any bundling call throws) so that `server.ts` could be imported for the language boundary.
On macOS no shim is needed.
