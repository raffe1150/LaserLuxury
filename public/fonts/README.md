# Dashboard typography

Manrope and Vazirmatn variable 400–700 WOFF2 subsets, self-hosted for the OdinLink dashboard. See the included SIL Open Font Licenses.

Manrope Latin: 24,576 bytes; optional Latin-ext: 15,240 bytes. Vazirmatn Arabic: 46,272 bytes. Unicode ranges and font-display: swap are declared in dashboard-signature.css. No font package or external runtime font service is required for these faces.

Sources: https://fonts.google.com/specimen/Manrope and https://github.com/rastikerdar/vazirmatn.
